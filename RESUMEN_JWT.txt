🔄 FLUJO DE AUTENTICACIÓN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. LOGIN
   Usuario → Credenciales → Servidor
   Servidor → Valida con password_verify()
   Servidor → Genera access_token + refresh_token
   Servidor → Crea sesión PHP (compatibilidad)
   Cliente → Guarda tokens en localStorage

2. REQUESTS
   Cliente → Agrega token al header
   Servidor → Valida token
   Servidor → Procesa request

3. RENOVACIÓN (Automática cada 5 min)
   Cliente → Verifica expiración
   Si < 15 min → Usa refresh_token
   Servidor → Genera nuevo access_token
   Cliente → Actualiza localStorage

4. LOGOUT
   Cliente → Limpia localStorage
   Servidor → Destruye sesión
   Cliente → Redirige a login
